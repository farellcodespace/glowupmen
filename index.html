Cara Menemukan Beban yang Tepat

Panduan step-by-step berbasis science untuk pemula

1
Mulai dari beban ringan

Selalu mulai lebih ringan dari yang kamu pikir. Untuk setiap gerakan baru, mulai dari beban paling ringan yang tersedia. Lakukan 10–12 rep dan nilai apakah rasanya “terlalu mudah”, “pas”, atau “terlalu berat”.

2
Gunakan RIR (Reps in Reserve)

RIR = berapa rep lagi yang bisa kamu lakukan setelah berhenti.

RIR 4–5terlalu ringan (naikkan beban)
RIR 2–3tepat untuk set pertama
RIR 1–2tepat untuk set terakhir (target kamu)
RIR 0failure (hindari di bulan pertama)

Tujuan: selesaikan semua set di RIR 1–2 — masih bisa 1–2 rep lagi tapi sudah sangat berat.

3
Tes beban baru

Kalau kamu baru mencoba suatu gerakan: coba 5–6 rep dengan beban yang terasa sedang. Kalau rep ke-5 terasa mudah, naikkan. Kalau terasa hampir maksimal, turunkan. Target: 3 set pertama di RIR 2–3, lalu set terakhir di RIR 1.

4
Progressive overload mingguan

Kalau semua set bisa diselesaikan dengan form bagus di RIR 1–2:

  • ›Gerakan compound (press, row, squat): naikkan 2.5 kg minggu depan
  • ›Gerakan isolasi (curl, lateral raise, fly): naikkan 1–1.5 kg
  • ›Kalau tidak bisa naik beban, coba tambah 1 rep per set dulu

Jangan naikkan beban kalau form mulai berantakan.

5
Tanda beban sudah tepat
✓ DO — beban pas
  • Form tetap bersih di semua set
  • Set terakhir terasa sangat berat tapi bisa diselesaikan
  • Ada “burning” atau pump di otot yang dilatih
  • Besoknya ada pegal ringan di otot yang benar
✕ DON'T — beban salah
  • Badan mulai ikut ayun atau momentum dipakai
  • Form berubah di tengah set
  • Tidak ada perasaan apapun di otot target
  • Sakit di sendi (bukan otot) — ini sinyal bahaya
